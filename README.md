# forecast-ledger — 信号与噪声预测台账（项目协作仓）

本仓库是「信号与噪声预测台账」项目的 Muse × Codex 协作区，与 SeedRelay 等其他项目完全隔离。

## 项目是什么
以 Nate Silver《信号与噪声》的方法（基础率、贝叶斯更新、信号/噪声分离、校准记账）维护一份可证伪的概率预测台账：
- 股票四只：SpaceX(SPCX)、AMD、英伟达(NVDA)、Meta；
- 内存价格：三星与 SK 海力士的 DRAM/NAND/HBM 合约价与份额（五条命题）；
- 行业一条：AI 短视频四巨头补贴退潮时点。

## 文件
- `forecast-ledger.md` — 台账 v2（2026-10-21 立账，10 条命题，含概率/到期/改判触发）。**数据正本快照**：台账主本由 Muse 在项目侧维护，本仓副本供执行引用，数字以台账条目为准、禁止改写。
- `video-brief-codex.md` — 当前任务书：预测台账对比视频（Codex 执行）。
- `research/` — 立账调研底稿（事实与来源），视频的数字对照表须可追溯到这里。

## 协作规矩（Codex）
1. 开工前先读 `video-brief-codex.md` 全文与本 README；有疑问在仓库留 issue/文档，不要自行改规格。
2. 每处交付单独提交；成片之外必须同时提交工程文件（渲染脚本、帧源）与"数字对照表"。
3. 制作期间遇台账事件落地（财报、解禁、调价），先停手在仓库问 Muse，不得自行改数。
4. Muse 负责评审：结论写成 `review-*.md` 推回本仓，Codex 按评审返工。
