# 常设指令：每周数据更新与对比（Muse → Codex/Luna，2026-10-21 创始人定版）

v3 制作项目已关闭（创始人终审通过）。自本周起转常态维护：**每周更新一次数据，由你做对比；格式不变，数据更新；有重大事件随时加更、随时调整。**

## 节奏

- 每周一次，建议周三（北京时间）执行：取最近一个完整美股交易周的收盘与当周新数据。
- 创始人喊「拉取」即按本单执行；财报、解禁、内存合约价发布、补贴政策变化等事件周可加更，不必等周三。

## 格式与口径（全部沿用 v3，不变）

- 七幕结构与数据口径不变：股票四只 → 内存趋势 → 三星 vs 海力士 → Seedance 官方价与渠道 → 竞争品牌价格带 → 十条命题总览。
- 概率与涨跌幅说「百分之……」；Seedance 与竞争品牌价格一律人民币（美元报价按 6.69 折算、官方锚用国内官方人民币价）；股票锚价以美元收盘判定、附人民币参考值。
- 官方价 / 渠道价 / 补贴价分开呈现，补贴价必须标注；禁止出现「买入 / 推荐 / 目标价」等荐股措辞，概率只能称「命题成立概率」。

## 每周交付（推入 `weekly/<YYYY-MM-DD>/` 目录）

1. **data-snapshot.md**：七部分最新数据全表。每项注明来源与日期：四只股票最新收盘（vs 锚价、52 周区间位置）、DRAM/NAND 环比与 HBM 情景/份额、Seedance 官方梯队、2.5 720p 渠道价差、国内补贴四家现状、竞争品牌价格带、十条命题当前 P 值总览。
2. **comparison.md**：逐项与上周快照对比，并逐条核对台账的改判触发条件：本周变了什么、是信号还是噪声、离触发还差多少。每条命题给出结论：**维持**，或**调整建议**（旧 P → 建议新 P + 依据）。
3. 任一价格周变动超过 5%、或任一触发条件命中，comparison 开头先汇总标明，不得埋在正文里。

## 纪律

- 概率调整只是建议：经 Muse 评审、创始人知悉后才写入台账正本；你不得自行改动台账的命题、P 值与到期日。
- 数据源纪律：股价用收盘价并注日期；内存价格用 TrendForce/集邦或主流财经媒体口径并注出处；Seedance 渠道价先查我方 price-watch 基线再补公开页面；无出处的数字不用，估算值必须标「约」。
- 首期执行日：2026-10-28（周三）。
